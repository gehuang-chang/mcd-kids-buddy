# mcd-kids-buddy（麦麦带娃官）

家长带娃吃麦当劳的一站式决策助手。基于麦当劳官方 MCP 真实数据，覆盖开心乐园餐推荐、玩具库存雷达、生日会方案、附近遛娃门店。

## 定位
参加「麦当劳程序员创意开发大赛」。榜单 300+ 参赛项目中亲子场景近乎空白，差异化明显。选题依据：麦当劳核心高频客群是亲子家庭（开心乐园餐、玩具、生日会）。

## 功能清单（按优先级）
- **MVP1 开心乐园餐智能推荐**：输入孩子年龄 + 场景（正餐/加餐/奖励）→ 输出套餐组合 + 热量糖量红线提示
- **MVP2 玩具雷达**：查当前玩具系列 + 门店有货情况（解决"孩子冲玩具去结果缺货"痛点）
- 二期：生日会助手（年龄+人数+预算→方案，可转发其他家长）
- 二期：周末遛娃路线（附近门店儿童游乐区/麦乐送筛选）
- 趣味钩子：遛娃战报晒图（"耗资86元，换得40分钟安宁+1个发光玩具"）

## 基于数据
麦当劳官方 MCP 能力（菜单、营养、门店、订单、优惠券等）。MCP 接入见 MCP_INTEGRATION.md。

## 分发策略
首发：长沙物业小区业主群 / 物业同行群的家长用户。README 放真实家长使用反馈截图。前 100 名门槛约 5 Star，发动亲友 + 业主群点 Star。
